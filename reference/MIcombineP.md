# Calculate p-values from \[mitools::MIcombine()\] object. This is an internal function.

Calculate p-values from \[mitools::MIcombine()\] object. This is an
internal function.

## Usage

``` r
MIcombineP(MIcombineRes, digits = 3)
```

## Arguments

- MIcombineRes:

  results from \[mitools::MIcombine()\].

- digits:

  integer indicating the number of decimal places (round) or significant
  digits (signif) to be used.

## Value

a numeric vector of the p-values.
